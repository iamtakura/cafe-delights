# Cafe Delights ☕🍰

A premium, modern website for **Cafe Delights**, featuring a dynamic menu, customer reviews, and a vibrant showcase of our offerings.

## 🚀 Features
- **Responsive Design**: Works perfectly on mobile, tablet, and desktop.
- **Dynamic Menu**: Categorized menu with parallax background sections.
- **Gallery**: Masonry-style grid showcasing our best shots.
- **Contact Map**: Interactive Google Map integration.
- **Real Reviews**: Wall of Love featuring our happy customers.

## 🛠️ Tech Stack
- **HTML5 & CSS3** (Vanilla with Variables)
- **JavaScript** (ES6+)
- **Vite** (Build Tool)

## 📦 Setup & Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/your-username/cafe-delights.git
    cd cafe-delights
    ```

2.  **Install Dependencies**
    ```bash
    npm install
    ```

3.  **Run Development Server**
    ```bash
    npm run dev
    ```

4.  **Build for Production**
    ```bash
    npm run build
    ```
